# SASE 授权弹窗自动关闭工具

## 快速安装

适用于 Apple 芯片（M1/M2/M3/M4 等）及 Intel Mac，macOS 13 或更新版本。
无需安装 Xcode、Python、Homebrew 或其他开发工具。无需 sudo。

1. 解压收到的 `SASEPopupCloser-Mac.zip`，保留文件夹内所有文件。
2. 双击 `Install.command`。它会安装关窗工具并设置当前账号登录后自动运行。
3. 在“系统设置 → 隐私与安全性 → 辅助功能”中，开启 **SASE Popup Closer**。
   如没有这个条目，点 `+`，选择 `~/Applications/SASE Popup Closer.app`。
   系统要求验证时，由你自己用 Touch ID 或本机密码批准。
4. 安装完成。工具每 3 秒检查一次匹配的授权窗口。

每台 Mac 都需要设备使用者亲自同意辅助功能权限；安装脚本不会自动写入系统
权限数据库，也不能把发送者电脑上的授权一起复制过来。

此工具由本地源码编译，采用临时签名，尚未使用 Apple Developer ID 签名或公证。
首次运行时 macOS 可能拦截安装脚本或应用。确认文件来源和源码后，可依据
Apple 官方说明，在“系统设置 → 隐私与安全性”中对这个具体文件选择“仍要打开”。
若公司管理策略不允许例外，请联系管理员；不要关闭 Gatekeeper 或 SIP。

- Apple 打开应用说明：https://support.apple.com/102445
- Apple 辅助功能授权说明：https://support.apple.com/guide/mac-help/mh43185/mac

## 原理

这是一个 Swift 编写、已编译的小型 macOS 后台应用。工作路径是：

`登录 → launchd 启动工具 → 每 3 秒寻找 SASE → 匹配授权窗口标题 → 点击系统关闭按钮`

它用 `NSRunningApplication` 定位应用标识 `com.aliyun.security.sase`，通过
macOS Accessibility API 读取这个应用的窗口标题。只有标题完全等于
`SASE服务授权` 或 `SASE Service Authorization` 时，才读取它的关闭按钮，
调用 `AXUIElementPerformAction(..., kAXPressAction)`，相当于手动点窗口红叉。

它只关闭这个授权提醒，不修改 SASE、不退出 VPN、不点击授权、不自动连接内网，
不采集屏幕图像，也没有联网代码。它不会自动关闭 SASE 的其他窗口或 macOS
系统权限窗口。弹窗可能短暂闪现；如果 SASE 修改了应用标识、标题或关闭按钮，
工具需要相应更新。工具不替代公司对 VPN 的准入规则。

辅助功能权限在系统层面可控制其他应用，并非系统限制为“仅控制 SASE”。
限定操作范围的是随包提供的源码，因此应只运行可信的这份程序。
工具不需要录屏、完全磁盘访问、自动化权限；不要给 SASE 开启这些权限。

## 安装内容

- `~/Applications/SASE Popup Closer.app`：关窗程序。
- `~/Library/LaunchAgents/local.hyper.sase-popup-closer.plist`：当前用户登录启动配置。
- `~/Library/Logs/SASEPopupCloser.log`：仅记录授权状态变化与关窗成功事件。
- `~/Library/Logs/SASEPopupCloser.error.log`：程序错误输出。

路径由安装脚本按朋友自己的账号自动生成，不含发送者的用户名或企业账号配置。
以 LaunchAgent 运行，不是 root 级系统服务，退出登录后不运行。

## 查看状态

在终端运行：

```sh
launchctl print "gui/$(id -u)/local.hyper.sase-popup-closer"
tail -20 "$HOME/Library/Logs/SASEPopupCloser.log"
```

- `Watcher active`：后台工具已有权限并在检查。
- `Waiting for Accessibility permission`：尚未授权，暂不操作窗口。
- `Closed SASE authorization window`：实际关闭了一次授权窗口。

从终端直接执行应用内的可执行文件可能继承终端的权限归属，因此不要用
这种方式的 `--check` 结果判断登录代理是否已获授权；以上述后台日志为准。

## 暂停或卸载

临时停止（下次登录恢复）：

```sh
launchctl bootout "gui/$(id -u)/local.hyper.sase-popup-closer"
```

卸载：双击 `Uninstall.command`。它先停止后台工具，再把程序、登录项和日志
移到当前账号的废纸篓；不卸载 SASE。可在系统设置中移除关窗工具的授权条目。

## 验证范围

打包时验证两种 CPU 架构的存在、应用签名完整性、窗口匹配逻辑，以及安装脚本
在临时目录生成当前账号路径的能力。安装流程不会通过重新登录 SASE 或主动连接
公司内网来触发测试。是否实际关窗，以后台日志中的成功事件和屏幕表现为准。
